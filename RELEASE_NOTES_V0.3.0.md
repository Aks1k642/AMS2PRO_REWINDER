# AMS 2 Pro Rewinder Lab v0.3.0 — usability and diagnostics

### Что исправлено
- Видимые причины, из-за которых недоступна команда выгрузки: LAN MQTT, Developer Mode (при наличии соответствующей телеметрии), состояние печати, активный AMS-слот и занятость AMS.
- Кнопки «Запросить статус принтера» и «Проверить готовность». Вместо молчаливой блокировки отображаются шаги устранения.
- **Одна экспериментальная штатная команда `unload_filament`**, без жёстко заданных температур и с ограничением повторной отправки 30 секунд. Подтверждение физического выполнения зависит от прошивки.
- Планы теперь можно брать в работу, вручную записывать массу по весам, ставить на паузу, завершать и снабжать примечаниями.
- Сохранение LAN Access Code с привязкой к серийному номеру принтера. В Windows шифрование DPAPI текущего пользователя; Android-клиент использует подключённый Windows-мост. Функция «Забыть код» удаляет запись для конкретного устройства.
- APK теперь имеет версию 0.3.0.

### Важно
**Это всё ещё исследовательский прототип.** Приложение НЕ управляет мотором AMS непрерывно, не умеет наматывать заданное количество граммов и НЕ измеряет реально перемотанную длину. Нельзя считать отправленный MQTT-запрос подтверждением завершённой выгрузки. Проверяйте на одной катушке без спайки, лично присутствуя у принтера.

На H2S, P2S и X2D физический тест в этой среде не проводился; прошивки могут различаться. Официальный закрытый Bambu Network Plugin не включён: поиск выполняется по SSDP, соединение через LAN MQTT.

### Сборки
- `AMS2ProRewinder-Windows-x64.exe` — локальный сервер + UI.
- `AMS2ProRewinder-Android-debug.apk` — Android интерфейс/офлайн-калькулятор; для MQTT-подключения требуется Windows LAN-мост.
