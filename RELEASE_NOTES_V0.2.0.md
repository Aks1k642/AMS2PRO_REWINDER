# AMS 2 Pro Rewinder Lab v0.2.0

## Изменения

- **Обнаружение принтеров в локальной сети** через SSDP (UDP/2021).
- Выбор H2S / P2S / X2D из списка с автоматическим определением IP и серийного номера. Серийный номер для MQTT-протокола по-прежнему используется, но вручную вводить его при успешном поиске не требуется.
- Резервное ручное подключение в раскрывающемся разделе на случай блокировки multicast / Bambu Studio.
- Android-клиент принимает любой выбранный порт Windows-моста в диапазоне 1024–65535.
- Проверки входящих SSDP пакетов и покрытие модульными тестами.
- В обеих сборках — обновлённый веб-интерфейс (Android использует LAN-мост на Windows).

## Важно

Это неофициальный исследовательский прототип. **Проприетарный Bambu Network Plugin в сборку не включён**: реализовано открытое SSDP-обнаружение и существующий LAN MQTTs мост.

Команда выгрузки филамента экспериментальная, требует присутствия оператора, свободного принтера и подтверждения безопасных условий. **Непрерывной перемотки и дозирования по граммам ещё нет.** Реальную работу с H2S/P2S/X2D необходимо проверить отдельно.

### Файлы
- `AMS2ProRewinder-Windows-x64.exe` — Windows x64, автономный локальный сервер и веб-интерфейс.
- `AMS2ProRewinder-Android-debug.apk` — Android оболочка для офлайн-калькулятора и подключения к Windows LAN-мосту; без самостоятельного управления MQTT.

Инструкции — в [README](https://github.com/Aks1k642/AMS2PRO_REWINDER#readme).
