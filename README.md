# AMS 2 Pro Rewinder Lab — v0.2.0

**Экспериментальное приложение для H2S / P2S / X2D и AMS 2 Pro.** Это не официальный продукт Bambu Lab.

## Реализовано

- Расчёт массы и длины по материалу, плотности и диаметру филамента. Сохранение расчётных планов в браузере, CSV-экспорт.
- Телеметрия принтера через LAN MQTTs (`8883`) с локальным кодом доступа, с отображением состояния печати и активного лотка.
- ДВА документированных варианта одиночной **штатной выгрузки**: `ams_change_filament` или `unload_filament`. Только после явного подтверждения, когда принтер свободен, ответ свежий, а загруженный в тракт слот совпадает с выбранным. Программа **никогда** не отправляет их в цикле.
- Работа из браузера Windows, из мобильного браузера в домашней LAN и в Android WebView-оболочке. Автономный расчёт работает и без принтера.

## Новое в v0.2.0 — поиск принтеров без ручного SN

- **Найти принтеры в сети** — приложение кратковременно слушает SSDP объявления Bambu Lab на UDP 2021 и показывает обнаруженные устройства.
- Выбор устройства автоматически подставляет его IP и серийный номер во внутреннюю MQTT-конфигурацию. **Вводить SN вручную не нужно** (если обнаружение удалось).
- Вводится только локальный LAN Access Code. Он остаётся в памяти сервера на время соединения.
- Кнопка поиска находится в Windows-веб-интерфейсе и в Android-клиенте, если Android подключён к Windows LAN-мосту. Автономная офлайн-страница поиск не выполняет.
- Если Bambu Studio занимает UDP 2021, принтер находится в другой подсети или мультикаст блокируется, раскройте **«Ручное подключение»** и введите IP + SN.
- Android WebView принимает пользовательский порт Windows-моста от 1024 до 65535 (ранее был фиксированный 8765).

**Официальный бинарный Bambu Network Plugin в проект не включён.** Его внутренняя ABI несовместима с прямым переносом в Python/Android и он закрыт. Здесь реализована открытая совместимая часть сетевого обнаружения Bambu (SSDP), а соединение по-прежнему использует LAN MQTTs. Серийный номер всё ещё требуется для MQTT-топика, но получается автоматически из объявлений принтера.

**Поддержка H2S/P2S/X2D:** H2S и P2S могут распознаваться по опубликованным префиксам SN. Если X2D или другая новая модель объявляет неизвестный код, выберите её модель вручную после обнаружения; IP и SN всё равно подставятся автоматически. Работа с реальными устройствами ещё не подтверждена.

## Не реализовано (ограничения)

- **Непрерывная перемотка** без ограничения штатной выгрузки прошивкой AMS 2 Pro.
- Фактический подсчёт перемотанных граммов/метров по датчику.
- Гарантированная остановка уже запущенного механического действия по кнопке / сети.
- Аппаратная проверка на H2S/P2S/X2D: эксперимент ещё не выполнялся на физических устройствах.

**НЕ СОЕДИНЯЙТЕ КАТУШКИ ПРИ ПЕРВОМ ТЕСТЕ.** Вышеперечисленные штатные команды могут двигать моторы, разогревать хотэнд или не выполняться на разных прошивках. Проверьте сначала одиночную выгрузку *обычного филамента* под наблюдением у принтера.

## Порт веб-интерфейса

При обычном запуске Windows EXE или `windows/START_WINDOWS.cmd` приложение спрашивает **номер HTTP-порта** (предложит 8765 или последний использованный). Нажмите Enter для значения по умолчанию либо введите другой свободный порт, например **8899**. Выбор сохраняется в пользовательском `settings.json` и будет предложен при следующем запуске. Если порт занят, приложение предложит выбрать другой.

Можно запускать без запроса:

```powershell
AMS2ProRewinder-Windows-x64.exe --port 8899
AMS2ProRewinder-Windows-x64.exe --auto-port
AMS2ProRewinder-Windows-x64.exe --no-port-prompt
```

Для доступа с телефона к серверу на ПК указывайте `--host 0.0.0.0 --port 8899`. Порт веб-интерфейса **не связан** с MQTT-портом принтера 8883. Не открывайте интерфейс в интернет.

## Windows

Требуется Python 3.10+ (без pip-зависимостей). Распакуйте проект в папку без кириллицы, запустите `windows/START_WINDOWS.cmd` — откроется интерфейс `http://127.0.0.1:8765/` с одноразовым токеном сеанса.

`windows/START_WINDOWS_LAN.cmd` позволит открыть интерфейс на Android по адресу, который напечатан в консоли: `http://<IP_ПК>:<выбранный_порт>/#token=...`. Для доступа с другого устройства может понадобиться разрешение в брандмауэре Windows (только частная сеть). **Не пробрасывайте порты в интернет**. Токен дает доступ к командам физического устройства — храните его как пароль. Код принтера остается в памяти процесса, в браузерных планах не сохраняется. Сам MQTT использует TLS с самоподписанным сертификатом (проверка сертификата принтера отключена — допустимо лишь для доверенной LAN).

Также можно открыть `web/index.html` локально и пользоваться автономным калькулятором без связи с принтером.

## Android

1. Проще всего: включите на Windows `START_WINDOWS_LAN.cmd`, откройте адрес с токеном в Chrome на Android в той же Wi-Fi сети.
2. Исходники APK-оболочки находятся в `android-source` (Java / Android Studio). В приложении нажмите `Офлайн` для расчётов или вставьте точную ссылку с `#token=` и нажмите `LAN`. **Android-оболочка не работает как самостоятельный MQTT-сервер**: требуется запущенный мост на Windows.
3. В GitHub Actions находится workflow для сборки Windows `.exe` и Android debug `.apk`. Сами сборки нужно получить после выполнения workflow; в исходном ZIP бинарников нет.

## Настройка принтера

1. На H2S / P2S / X2D включите поддерживаемый режим LAN и доступ к локальному API (где доступен Developer Mode). Откройте Rewinder, нажмите «Найти принтеры», выберите устройство и введите LAN Access Code. IP и SN подставятся автоматически. При ошибке используйте ручное подключение.
2. Убедитесь, что принтер свободен, на нём нет печати, а AMS 2 Pro подключён и **одна штатная катушка** загружена в тракт.
3. Подключитесь в приложении. Проверьте телеметрию, `gcode_state` и `tray_now`.
4. Первую команду выполняйте только при личном присутствии у принтера, без внешней катушки, без спайки и с возможностью безопасной физической остановки. Экспериментальную команду нажимать только один раз. Результаты команды отображаются отдельно от фактического количества намотки.

## Расчёт

Масса 1 м филамента диаметром `d` мм и плотностью `ρ` г/см³:

`г/м = π × d² / 4 × ρ`.

Длина в метрах: `масса_г / (г/м)`. Это оценка: точное значение зависит от допусков диаметра, состава и влаги.

## API

`GET /api/status`, **`GET /api/discover`**, `POST /api/connect`, `POST /api/disconnect`, `POST /api/unload`. Заголовок `X-Session-Token` обязателен для всех запросов. Данные авторизации не сохраняются на диск. `POST /api/unload` дополнительно проверяет состояние печати, свежесть и выбранный активный слот AMS; обходит штатную автоматику **не пытается**.
